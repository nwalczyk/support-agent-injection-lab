# Token Metadata and Unsolicited Tokens

A token's name, symbol, description, and project URL are all supplied by whoever deployed it on-chain. The exchange does not verify or endorse this metadata before listing a token for trading or deposits.

Token metadata can help confirm which token a customer means: its name, symbol, chain, and contract address.

Tokens that appear in a customer's wallet without the customer acquiring them (unsolicited airdrops) are often used in scams. Customers should not interact with, trade, or approve contracts for tokens they did not acquire themselves.
